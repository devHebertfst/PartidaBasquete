# PartidaBasquete

Aplicativo Android nativo para controle de pontuação de uma partida de basquete.

## Tecnologias

- Kotlin
- Android SDK
- Gradle Wrapper
- Android Studio

## Pré-requisitos

Antes de rodar o projeto, tenha instalado:

- Android Studio atualizado
- JDK 21
- Android SDK configurado no Android Studio
- Um emulador Android ou celular físico com depuração USB ativada

## Configurações do projeto

- `minSdk`: 28
- `targetSdk`: 36
- `compileSdk`: 36
- Compatibilidade Java: 21

## Como rodar no Android Studio

1. Abra o Android Studio.
2. Selecione `Open` e escolha a pasta do projeto.
3. Aguarde o Gradle sincronizar as dependências.
4. Inicie um emulador Android ou conecte um dispositivo físico.
5. Clique em `Run` para executar o app.


## Observações

- O arquivo `local.properties` depende do caminho local do seu Android SDK.
- Caso o projeto não sincronize, confirme se o SDK Android está instalado corretamente no Android Studio.
- Se estiver usando celular físico, habilite a opção de desenvolvedor e a depuração USB.
